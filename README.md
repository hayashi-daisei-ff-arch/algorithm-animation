# データ構造と探索：アニメーション教材

## 起動

ダウンロードしたZIPを展開し，`index.html`をブラウザで開きます．インストールやビルド，外部ライブラリは不要です．同じフォルダ内のHTML・CSS・JavaScriptをまとめて配置してください．

## 教材

| データ構造 | 操作・説明 |
| --- | --- |
| 配列 | 添字によるアクセス，要素を移動して挿入・削除 |
| 連結リスト | 先頭から参照をたどるアクセス，参照先を変更する挿入・削除 |
| スタック | push／pop，上端からの追加・取り出し |
| キュー | enqueue／dequeue，末尾への追加・先頭からの取り出し |
| 木構造 | ルート・親・子・葉，2種類の木 |

| 探索 | 表示 |
| --- | --- |
| 線形探索 | 比較する要素，確認済み要素，比較回数 |
| 二分探索 | 中央の要素，残る探索範囲，比較回数 |
| 深さ優先探索 | 訪問順，現在の経路，親へ戻る操作 |
| 幅優先探索 | 訪問順，待機中のキューへの追加・取り出し |

タブを切り替えて使用します．「次へ」で1操作ずつ進み，「戻る」やスライダーで任意の手順を確認できます．自動再生は途中停止でき，速度も変更できます．投影表示では補足説明を隠し，図と現在の手順を中心に表示します．動きの軽減をOSで設定している場合，移動時の補間アニメーションは省略します．

数値は−999～999の整数を最大12個まで指定できます．入力・設定はブラウザ内だけで扱い，送信・保存しません．設定変更後は「設定を反映」を押してください．標準の例へ戻すこともできます．

## 数え方

添字・挿入位置は0始まりです．挿入位置0は先頭，元の要素数と同じ位置は末尾を意味します．線形探索・二分探索の比較回数は「探索値と比較した要素の個数」です．操作ステップ数とは異なります．二分探索は昇順を前提とし，中央2個の場合は左側を選びます．深さ優先・幅優先探索は子を左から右へ調べ，訪問順には初回の訪問だけを含めます．

配列の挿入は，必要な空き領域を確保できている場合を示します．配列の容量拡張や，連結リストの領域確保・解放の内部処理は省略しています．キューの図では，残る要素を左へ詰めずfrontを進めます．

## GitHub Pagesで公開

1. GitHubでリポジトリを用意します．
2. このフォルダの`index.html`・`styles.css`・`engine.js`・`app.js`・`.nojekyll`をリポジトリのルートへ追加します．フォルダ自体ではなく，中のファイルを配置します．
3. リポジトリの`Settings → Pages`を開きます．
4. `Build and deployment`の`Source`で`Deploy from a branch`を選び，ブランチを`main`，フォルダを`/ (root)`として保存します．ブランチ名が異なる場合は，ファイルを配置したブランチを選びます．
5. 公開処理の完了後，Pages設定画面に表示されるURLを開きます．

GitHub Freeでの公開には，パブリックリポジトリを使用します．既存サイトのサブフォルダに置く場合も，相対パスを使用しているため利用できます．既存サイトのルートファイルを上書きせず，専用のサブフォルダに全ファイルを配置してください．

公式手順：https://docs.github.com/ja/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 直接開くタブ

URL末尾に`#array`，`#list`，`#stack`，`#queue`，`#tree`，`#linear`，`#binary`，`#dfs`，`#bfs`を付けると，そのタブから開けます．
